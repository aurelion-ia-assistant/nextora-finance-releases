# Nextora Finance Tracker — official releases

This repository contains only published installers, signed update manifests, checksums and
release notes for **Nextora Finance Tracker** by NEXTORA DIGITAL.

- Downloads: https://github.com/aurelion-ia-assistant/nextora-finance-releases/releases
- Update manifests: `channels/<stable|beta|preview>/{{target}}-{{arch}}.json`
- Release metadata: `metadata/<channel>.json`

No application source code, signing keys, credentials or customer data are stored here.
All updates are cryptographically signed and verified by the Tauri updater before installation.
